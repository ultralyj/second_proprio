# 02 行为克隆：低监督误差为何不等于可靠控制

lesson_id: `02-bc-shift` · 生成日期：2026-10-29 · 建议用时：20 分钟

前置：[01 统一建模](01-shared-model.md)。本节目标：分清“拟合好专家数据”和“在自己访问的状态上可靠”，并用一个反例验证两者不等价。

## 一个直觉

专家把物体稳定握在目标姿态，示范里几乎没有“滑到指尖后怎样救回来”。模型可以在这些稳定样本上预测得很好。部署时一次小偏差让物体接触位置改变；模型开始面对训练集里很少出现的输入。后续动作又可能继续放大偏差。

这里需要区分两个问题：模型有没有学会数据中存在的规律，以及数据有没有覆盖它执行时需要的规律。增加网络容量可能缓解前者，却不会凭空提供后者的正确标签。

## 关键公式

BC 用专家访问状态训练：

$$
\hat\theta=\arg\min_\theta
\mathbb E_{s\sim d^{\pi^*}}
\left[\ell\bigl(\pi_\theta(s),\pi^*(s)\bigr)\right].
$$

部署关心的却是：

$$
\mathbb E_{s\sim d^{\pi_{\hat\theta}}}
\left[\ell\bigl(\pi_{\hat\theta}(s),\pi^*(s)\bigr)\right].
$$

$\pi^*$ 是专家，$d^{\pi^*}$ 是专家的平均访问分布，$d^{\pi_{\hat\theta}}$ 是学习者的访问分布，$\ell$ 衡量动作差异。两个期望里的函数可以相同，但采样分布不同。只汇报前一个值，无法确认第二个值也小。

一个常见误差累积直觉是：先考虑确定性专家，假设在每个时刻的专家状态分布 $d_k^{\pi^*}$ 上，学习者动作与专家不同的概率都不超过 $\epsilon$。这里的逐时刻假设比只约束平均访问分布更强。在相同初始分布与动力学下，首次动作偏离之前可以沿专家轨迹比较；联合界给出前 $t$ 步曾经犯错的概率不超过 $\min(1,t\epsilon)$。一旦离开熟悉状态后可能持续犯错，则使用较松的 $t\epsilon$ 上界对整个时域求和会出现

$$
\sum_{t=1}^{T} t\epsilon
=\frac{T(T+1)}2\epsilon=O(T^2\epsilon).
$$

这是说明最坏情形的直觉，不是每个连续控制任务的精确预测，也不能把分类错误率直接换成任意 MSE。正式结论还依赖成本界和问题假设。[Ross 与 Bagnell（2010）](https://proceedings.mlr.press/v9/ross10a/ross10a.pdf)分析了这一序列决策中的累积问题。

## 最简代码

完整可运行代码：[bc_shift.py](../examples/bc_shift.py)。运行 `uv run python courses/examples/bc_shift.py`。

我们故意构造一个很窄的示范集：专家已经停在目标 $s=0$，所有动作也为零。策略是无偏置线性层 $a=ws$；不论 $w$ 取什么值，训练损失都是零。因此数据无法确定正确的恢复方向。这是数据覆盖的反例，不是对真实示范集的模拟。

```python
policy = make_policy()
# 极简演示只收集专家已经稳定在目标处的状态，刻意暴露覆盖问题。
expert_states = torch.zeros(16, 1)
loss = fit(policy, expert_states, expert(expert_states))
visited = rollout(policy)
```

这是源码 `main()` 的连续片段；`make_policy()` 创建初始斜率为 0.2 的线性层，`expert()` 返回 $-0.5s$，`fit()` 执行 MSE 训练，`rollout()` 收集闭环状态。各辅助函数都在同一个链接文件内。

训练后从扰动状态 $s_0=1$ 执行。环境仍为 $s_{t+1}=s_t+a_t$：当前策略使状态不断偏离目标，而真正的专家动作 $a^*=-0.5s$ 会逐步恢复。示例会打印零训练 MSE，以及明显增长的第 11 步偏差。

这个反例同时改变了评估起点，所以它直接验证的是“专家数据没有覆盖恢复状态”。真实闭环中，动作误差也能产生新的访问状态；不要把本实验误称为原论文误差上界的数值证明。

## 实验与局限

把专家数据改成 `torch.linspace(-1, 1, 16).reshape(-1, 1)` 再训练，比较恢复能力；随后把策略初始斜率改成负值，观察在零数据下模型表现为何取决于初始化。

更实际的评估应把训练误差、独立示范验证误差、闭环成功率、扰动恢复和覆盖范围分开报告。数据增广是否有效，取决于增广后标签仍否正确；旋转图像却保持原动作，未必符合机器人的坐标系。
