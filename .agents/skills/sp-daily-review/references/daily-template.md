# 每日复盘阅读模板

下面是结构，不是需要原样复述的内容。按当天重要目标组织，避免把一天写成修复
连接、运行命令和修改文件的时间线。正文每项应能回答“做了什么重要事，结果怎样”。

```markdown
# YYYY-MM-DD

## 今天做了什么

- 一项重要事情，以及它留下的成果、决定或当前进展。必要时自然说明仍待验证的部分。
- 另一项真正值得记住的事情及其结果；没有就不凑数。

## 还没收尾

只说明影响主要目标的未完成部分或重要阻碍；没有则省略整节。

## 接下来

1. 与今天成果衔接的一个具体动作。
2. 有根据的下一件事，可用“可以考虑”区分建议；最多三项。

来源：实际读取的记录类型及覆盖时间；必要时用半句说明缺少哪部分记录。
```

“完成部署”与“准备好部署方案”是不同结果；“读到某个概念”不等于“已经掌握”。
通过准确措辞区分即可，不添加完成证据表、工具清单或来源路径索引。需要保留的
核验信息在 `private/review-context/`，正文不重复展开。
