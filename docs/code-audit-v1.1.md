# v1.1 代码审计

审计日期：2026-11-02。应用版本：`1.1.0`。范围包括应用 Python、桌面 TypeScript／Rust、
构建入口、配置模板、测试与课程示例。学术内容沿用现有资料，不把外部论文或聊天中的文字当执行指令。

## 注释与代码组织

- Python 使用 Google YAPF、80 列和中文说明；关键公共接口按 `Args`、`Returns`、`Raises`
  说明输入、返回及失败语义。简短的自明函数保留一句中文职责说明，避免逐行复述代码。
- 用 AST／tokenize 检查 Python 的说明性注释和 docstring，人工复核其是否符合实际行为；
  TypeScript／Rust 的模块说明及复杂分支说明也使用中文。保留标准 API、类型名称及工具指令。
- 合并 JSON 原子写入、配置摘要、路径边界、部署 Socket 客户端、任务筛选的重复实现。
  高频状态计数和单任务读取直接查询 SQLite，不再解码全部任务历史。
- 将本机管理子进程执行提取到 `process.rs`，统一输出排空、大小限制和总超时。
  其余模块保留现有边界，未因单纯的行数增加额外封装。

## Python 与构建文件职责

| 文件 | 职责与审查重点 |
|---|---|
| `__init__.py` | 包说明及统一应用版本；部署运行时直接复用版本常量。 |
| `__main__.py` | Python 模块启动入口，仅转交 CLI。 |
| `cli.py` | 本机、兼容 CLI 和轻量服务器的命令路由；后台在线时通过 RPC 操作同一队列。 |
| `config.py` | 配置校验、原子保存、路径边界和修订摘要；拒绝数据目录重叠及无效时区。 |
| `scheduler.py` | 按配置时区补建任务、重试筛选、离线课程及关心提醒合并。 |
| `store.py` | SQLite 状态、事件、失败预算及远端信封合并；任务确认与内容发布分离。 |
| `sync.py` | 脱敏配置和任务信封的 SSH 交换；不传聊天、模型凭据或论文附件。 |
| `deployment.py` | 兼容 CLI 的 launchd 安装和轻量服务器 systemd 文件生成。 |
| `desktop_deployment.py` | 打包运行时安装、备份、停启和回退；停止时由服务原子判断是否空闲。 |
| `rpc.py` | 同用户 Unix Socket 客户端；响应标识、结构、大小及错误校验。 |
| `daemon.py` | 桌面服务编排：接口、队列、独立提醒、串行任务、取消、发布确认和同步快照。 |
| `desktop_worker.py` | 隔离工作区中的单次重任务入口，输出真实阶段事件及结果。 |
| `documents.py` | 文档路径、草稿、乐观版本检查、修订历史、候选及可恢复多文件发布。 |
| `desktop_content.py` | 只读内容查询与个人记录接口；查询不生成课程或笔记模板。 |
| `papers.py` | arXiv 元数据、筛选、下载、资源准备及本地缓存。 |
| `course.py` | 课程准备、来源与代码验收、笔记反馈匹配；生成和已学状态分离。 |
| `personal.py` | 关系天数、手工记录、导入聊天及复盘输入准备。 |
| `review_sources.py` | 只读来源发现、规范化、日期覆盖和来源指纹；隔离损坏记录。 |
| `review_refresh.py` | 节流检查新增来源，登记复盘更新；不在查询接口触发模型。 |
| `runner.py` | 单次业务任务、Codex 执行与结果验收，以及兼容 CLI 的首页输出。 |
| `packaging/engine_entry.py` | 冻结运行时入口，区分服务部署与普通命令。 |
| `packaging/build_app.py` | 按锁定依赖构建 Python 运行时、Tauri App 并验证本机签名。 |
| `courses/examples/*.py` | 各章节的唯一可运行代码来源，默认 CPU；不包含后台调度行为。 |

## 桌面文件职责

| 文件或文件组 | 职责与审查重点 |
|---|---|
| `main.tsx`、`App.tsx` | React 启动、导航、主题与后台连接状态。 |
| `api.ts` | 共享接口类型、Tauri 调用及展示格式。 |
| `DocumentView.tsx` | 正文编辑、草稿、历史和候选交互；保存回包不覆盖后续输入。 |
| `Markdown.tsx`、`latexDelimiters.ts` | Markdown／数学／管线／图片预览及公式分隔符兼容；轮询不重建媒体。 |
| `PaperRating.tsx`、`UI.tsx` | 论文评分与通用交互部件。 |
| `Today.tsx` | 自我叩问、折叠分组、待处理事项确认。 |
| `Library.tsx` | 论文／课程／复盘的列表筛选、选择和笔记入口。 |
| `Care.tsx` | 日期、心情及行动记录；迟到请求不覆盖新日期或新输入。 |
| `Tasks.tsx` | 任务筛选、状态、详情、暂停、取消及单项重试。 |
| `Settings.tsx` | 配置草稿表单、校验结果与显式保存。 |
| `styles.css`、各局部 CSS | 页面布局、明暗主题和组件样式，不承载业务状态。 |
| `src-tauri/src/main.rs` | 原生入口。 |
| `src-tauri/src/lib.rs` | 受限桥接、窗口／菜单栏生命周期、文件打开与后台管理。 |
| `src-tauri/src/notification.rs` | macOS 通知权限及提交回执；提交成功不等于用户已读。 |
| `src-tauri/src/process.rs` | 有界管理命令执行；并发排空 stdout／stderr，防止管道堵塞。 |
